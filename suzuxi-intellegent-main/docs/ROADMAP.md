# Roadmap setelah starter v1.0

1. Implement Supabase Auth, admin bootstrap dan role-based access.
2. Tambah UI CRUD penuh untuk katalog, knowledge documents dan social accounts.
3. Implement event mapping untuk Meta Page/Instagram webhook sesuai permission yang disetujui.
4. Implement WhatsApp inbound webhook parsing, message templates, opt-out dan delivery receipts.
5. Implement vector search/RAG untuk dokumen terverifikasi.
6. Implement queue worker dengan lock/claim atomik, retry/backoff, dead-letter queue dan observability.
7. Tambah inbox realtime dan human takeover.
8. Tambah consent capture form/lead ads flow dan bukti persetujuan.
9. Tambah rate limiting, CSRF/origin protection, audit log dan automated tests.
